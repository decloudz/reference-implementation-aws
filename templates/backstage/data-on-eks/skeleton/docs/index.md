# Data on EKS

This template creates a comprehensive data platform on Amazon EKS (Elastic Kubernetes Service). It provides the necessary infrastructure and services for running data workloads, analytics, and machine learning pipelines on Kubernetes.

## Features

- **Scalable Data Platform**: Auto-scaling data processing capabilities on EKS
- **Analytics Services**: Pre-configured analytics tools and frameworks
- **Data Storage**: Integrated storage solutions for data lakes and warehouses
- **ML/AI Support**: Machine learning pipeline infrastructure and tools

## Platform Components

- EKS cluster optimized for data workloads
- Apache Spark for large-scale data processing
- Apache Airflow for workflow orchestration
- MinIO for S3-compatible object storage
- Jupyter notebooks for data science workflows

## Getting Started

1. Use this template to create your data platform on EKS
2. Configure cluster sizing and storage requirements
3. Deploy the platform using the provided manifests
4. Set up data pipelines and analytics workflows

## Supported Workloads

- **Batch Processing**: Large-scale data transformation jobs
- **Stream Processing**: Real-time data processing pipelines
- **Machine Learning**: Training and inference workloads
- **Analytics**: Interactive data analysis and visualization

## Related Services

This platform integrates with:
- AWS data services (S3, RDS, Redshift)
- Data visualization tools (Grafana, Superset)
- ML platforms (Kubeflow, MLflow)
- Monitoring and observability tools
