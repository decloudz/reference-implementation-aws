## ArgoCD Multi-Source Configuration

This repository uses ArgoCD's multi-source feature:

1. **Chart Source**: External Helm chart from `${{ chartRepo }}`
2. **Values Source**: Environment-specific values from this Git repository

The configuration in each `application.yaml` looks like:
```yaml
sources:
  - repoURL: ${{ chartRepo }}
    chart: ${{ chartName }}
    targetRevision: ${{ chartVersion }}
    helm:
      valueFiles:
        - $values/environments/ENV_NAME/${{ chartName }}/values.yaml
  - repoURL: https://cnoe.localtest.me:8443/gitea/giteaAdmin/${{ repoName }}
    targetRevision: main
    ref: values
```

## Troubleshooting

### Application Not Syncing

1. Check ArgoCD application status
2. Verify values.yaml syntax is valid YAML
3. Check chart version compatibility  
4. Review ArgoCD application logs

### Multi-Source Issues

1. Ensure ArgoCD version supports multi-source (2.6+)
2. Check `ref: values` is set on the Git source
3. Verify `valueFiles` path is correct

### Service Not Accessible

1. Check ingress configuration in values.yaml
2. Verify service is running in correct namespace
3. Check secrets are properly configured
4. Review application logs in Kubernetes
